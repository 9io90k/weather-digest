# Weather Digest CLI

Консольная утилита на Node.js для получения и кэширования сводки прогноза погоды по городам на базе Open-Meteo API.

## Требования

* Node.js версии **>= 20.0.0** (используется нативная поддержка fetch, AbortController и node:util parseArgs).
* Доступ к сети Интернет.
* Внешние npm-зависимости отсутствуют (проект выполнен исключительно на стандартных библиотеках).

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd weather-digest 
   ```
   Убедитесь в наличии файла package.json с "type": "module". Установка сторонних пакетов через npm install не требуется.

2. Использование:
  ```bash
    node src/index.js --city "<ГОРОД_1, ГОРОД_2>" [опции]
  ```

## Параметры командной строки

| Флаг | Тип | Обязательный | По умолчанию | Описание |
| :--- | :--- | :---: | :---: | :--- |
| `--city` | `string` | **Да** | — | Название одного или нескольких городов через запятую (например, `"Москва, Казань"`). |
| `--days` | `number` | Нет | `3` | Количество дней прогноза (допустимо от `1` до `7`). |
| `--no-cache` | `boolean` | Нет | `false` | Принудительный обход локального кэша и повторный сетевой запрос. |

## Переменные окружения

| Переменная | По умолчанию | Описание |
| :--- | :--- |  :--- |
| TIMEOUT_MS | 5000 | Таймаут ожидания ответа API в миллисекундах |
| REPORTS_DIR | reports| Каталог для сохранения JSON-файлов кэша |
| GEOCODING_API_URL | https://geocoding-api.open-meteo.com/v1/search | Эндпоинт геокодинга Open-Meteo |
| FORECAST_API_URL | https://api.open-meteo.com/v1/forecast | Эндпоинт прогноза Open-Meteo

## Примеры запуска

1. Базовый запрос на 3 дня: 
    ``` bash
    node src/index.js --city "Казань"
    ```
2. Запрос прогноза на 7 дней:
    ``` bash
    node src/index.js --city "Москва" --days 7
    ```
3. Параллельная обработка нескольких городов:
    ``` bash
    node src/index.js --city "Москва, Берлин, Мадрид" --days 2
    ```
4. Принудильное обновление кэша:
    ``` bash
    node src/index.js --city "Париж" --no-cache
    ```
## Коды завершения
- 0 - Все переданные города успешно обработаны.
- 1 - Некорректные аргументы CLI либо ошибка получения данных хотя бы по одному из городов.
